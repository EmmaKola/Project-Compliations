### 1. Nova Med Solutions Performance Analytics
 - **About Project** - This project delivers a full performance analysis for Nova Med Solutions, a pharmaceutical distributor serving hospitals, resellers, smaller distributors, and direct users across multiple markets. The analysis evaluates sales performance, profitability, product demand, customer demographics, buyer type, and geographic revenue trends from 2022 to 2026.
